## 3. 待学习内容（按优先级）

### 优先级 A：阶段 0（必须最先做）

- [ ] **执行 `sw_vers` 确认操作系统版本**
- [ ] **确认 JDK 版本**（`java -version`），对照项目要求
- [ ] **确认 Maven / Gradle 是否已装**
- [ ] **确认数据库是否已装或选 Docker**
- [ ] **clone sjava 仓库**（用户同意后）
- [ ] **核对 README / pom.xml** → 确认项目实际身份（若依？哪个版本？）
- [ ] 在 IDE 中能成功打开并启动项目

### 优先级 B：阶段 1（基础 Java）

- 类、接口、方法、参数、返回值
- 对象、集合、常见数据类型
- 条件判断、循环、异常
- Spring 常见注解
- 依赖注入

### 优先级 C：阶段 2（架构与调用链）

- 真实项目里的 Controller / Service / Mapper 各自职责
- 一次前端请求到 SQL 的完整链路
- MyBatis 的基本数据访问方式

### 优先级 D：阶段 3+

- 基础 CRUD 实操
- 独立完成小型模块
- 代购业务核心功能
- 安全运维

详见 `ROADMAP.md`。
