## 2. 能力状态（5 档）

### 2.1 状态定义

| 状态 | 含义 | 升级条件 |
|---|---|---|
| ⬜ 未验证 | 尚无证据 | 等待学习 |
| 🔄 学习中 | 正在学习，还不能独立完成 | 通过初步测试 |
| ✅ 已掌握 | 已通过独立操作 / 解释验收 | — |
| ⚠️ 需要复习 | 近期遗忘或应用困难 | 重新学习 |
| 🔁 重新验证中 | 原标 ✅，新证据表明薄弱 | 完成再次验收 |

AI **不得**自行从 ⬜ 直接升 ✅。必须经过"用户独立完成 / 解释 / 复述"。

**升级必须带可验证证据**（命令输出 / 测试结果 / 用户复述 / 截图 / 操作日志），空口说"我懂了"或"应该可以"不算。

### 2.2 降级流程（防"假阳性掌握"）

1. 用户答错 / AI 发现用户不能独立操作 → AI 主动评估错误类型
2. 错误分级：
   - 局部细节遗漏（参数名忘了） → 标 ⚠️
   - 概念理解不完整 → 标 ⚠️
   - 完全不会应用 → 退回 🔄 学习中
   - 之前 ✅ 但反复遗忘 → 标 🔁 重新验证中
3. AI **必须**在 `SESSION_LOG.md` 当次记录里说明降级原因
4. 不得为"不打击用户信心"而保留原标

## 3. 待学习内容（按优先级）

### 优先级 A：阶段 0（必须最先做）

- [ ] **执行 `sw_vers` 确认操作系统版本**
- [ ] **确认 JDK 版本**（`java -version`），对照项目要求
- [ ] **确认 Maven / Gradle 是否已装**
- [ ] **确认数据库是否已装或选 Docker**
- [ ] **clone sjava 仓库**（用户同意后）
- [ ] **核对 README / pom.xml** → 确认项目实际身份（若依？哪个版本？）
- [ ] 在 IDE 中能成功打开并启动项目

### 优先级 B：阶段 1（基础 Java）

- 类、接口、方法、参数、返回值
- 对象、集合、常见数据类型
- 条件判断、循环、异常
- Spring 常见注解
- 依赖注入

### 优先级 C：阶段 2（架构与调用链）

- 真实项目里的 Controller / Service / Mapper 各自职责
- 一次前端请求到 SQL 的完整链路
- MyBatis 的基本数据访问方式

### 优先级 D：阶段 3+

- 基础 CRUD 实操
- 独立完成小型模块
- 代购业务核心功能
- 安全运维

详见 `ROADMAP.md`。
