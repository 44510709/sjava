## 3. 待学习内容（按优先级）

1. **环境阶段**（最早做）
   - clone sjava 仓库到本地
   - 确认 Java / Maven / 数据库版本与项目要求一致
   - 能在 IDE 中成功打开并启动项目
2. **基础调用链阶段**
   - 追踪一次「登录 / 列表查询」的完整链路
   - 学会 3 种调试方式（断点 / 日志 / SQL 打印）
3. **CRUD 实战阶段**
   - 独立完成 1 个普通表的增删改查
   - 加上分页、模糊查询、批量操作
4. **权限与字典阶段**
   - 学会看若依权限表与字典表
   - 给一个新模块加权限控制
5. **进阶业务阶段**（按需）
   - 业务订单、批次、支付、退款、海关（如适用）
