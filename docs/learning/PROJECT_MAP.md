## 3. 修改地图（哪里能改 / 不能改）

| 文件/目录 | 谁能改 | 注意事项 |
|---|---|---|
| `controller/` 自己写的 | 用户 / AI（限业务） | 不动框架自带 |
| `service/` 自己写的 | 用户 / AI（限业务） | 事务边界要明确 |
| `mapper/` 自己写的 | 用户 / AI | SQL 全部走 `${}` 白名单 |
| `resources/mapper/*.xml` | 用户 / AI | 同上 |
| `resources/application*.yml` | 谨慎 | 密钥不进 Git |
| 框架代码（`com.ruoyi.*` 默认） | **不轻易改** | 升级时再统一处理 |
| `pom.xml` | 谨慎 | 依赖升级先查兼容性 |
| `generator/` 模板 | **不轻易改** | 改了会影响生成代码 |
